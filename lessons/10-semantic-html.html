Semantic HTML

Semantic elements describe what content means, not just how it looks. Screen readers, search engines and other developers all benefit.

Lesson 10 Intermediate

💡 The Concept

  • header — introductory content: logo, page title, search box.
  • nav — a block of navigation links.
  • main — the page's unique core content (use once).
  • section — a themed group of content, usually with a heading.
  • article — a self-contained unit: blog post, product card, comment.
  • aside — tangentially related content: sidebars, related links.
  • footer — closing info: copyright, sitemap, contact.
  • Bonus: time and figure add even more meaning to specific content.
💡 Why it matters: Replacing 20 nested divs with semantic tags improves accessibility and SEO for free.

📝 Source Code

Semantic skeleton 
<body>
  <header> Logo and title </header>
  <nav> Home · News · Contact </nav>
  <main>
    <article>
      <h1>Article title</h1>
      <p>Published <time datetime="2026-08-07">7 Aug</time></p>
      <p>Article body...</p>
    </article>
    <aside> Related links </aside>
  </main>
  <footer> Copyright notice </footer>
</body>

✅ Key Takeaways

Remember

  • Semantic tags describe meaning: header, nav, main, section, article, aside, footer.
  • Use one main per page for the primary content.
  • Semantic HTML improves accessibility and SEO without any extra code.
  • Reach for these elements before defaulting to div.
