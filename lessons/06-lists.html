Lists

Three list types cover almost every scenario: unordered (ul), ordered (ol) and description lists (dl).

Lesson 06 Beginner

💡 The Concept

  • ul + li — bulleted list when order doesn't matter (shopping lists, nav menus).
  • ol + li — numbered list when order matters (steps in a recipe, rankings). The type attribute switches numbering (1, A, a, I, i) and start sets the first value.
  • dl with dt (term) and dd (description) — glossary-style pairs.

Lists nest inside each other freely — just remember an li is the only valid direct child of ul or ol.

📝 Source Code

The three list types 
<ul>
  <li>Apples</li>
  <li>Bananas</li>
</ul>

<ol type="1" start="1">
  <li>Mix flour and sugar.</li>
  <li>Bake for 30 minutes.</li>
</ol>

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
</dl>

✅ Key Takeaways

Remember

  • ul for unordered, ol for ordered, dl for term/description pairs.
  • Only li can be a direct child of ul / ol.
  • Lists nest — a nested list goes inside an li.
  • Use type and start to control numbering.
