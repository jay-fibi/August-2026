Meta Tags & SEO

meta tags live in the head and are invisible to visitors — but they shape search results, social previews and mobile rendering.

Lesson 14 Intermediate

💡 The Concept

  • charset — declares UTF-8 so emoji and special characters render.
  • viewport — the magic tag that makes pages usable on phones; it sets the width to the device width.
  • description — the blurb under your site name in Google results.
  • author, keywords — informative, minor SEO weight.
  • robots — instruct crawlers (index, noindex, nofollow).
  • Open Graph (og:*) and Twitter Card (twitter:*) — control how your page previews when shared on social media.

This very page uses meta tags — view the page source to see them in action (including the og:title and og:description for social sharing).

📝 Source Code

The essential meta tags (all inside <head>) 
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Learn HTML the hands-on way.">
<meta name="author" content="HTML Learning Hub">
<meta name="robots" content="index, follow">

<title>Page Title Shown in Search Results</title>

<!-- Social sharing previews -->
<meta property="og:title" content="HTML Learning Hub">
<meta property="og:description" content="20 hands-on HTML lessons.">
<meta property="og:type" content="website">
<meta name="twitter:card" content="summary_large_image">

✅ Key Takeaways

Remember

  • meta charset and meta viewport belong on every page.
  • Write a compelling description — it's your advert in search results.
  • Open Graph and Twitter Card tags control social media previews.
  • Meta tags live in the head; they are invisible on the page itself.
