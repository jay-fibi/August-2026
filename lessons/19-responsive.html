Responsive Design

Responsive pages adapt to any screen. Three key tools: the viewport meta tag, CSS media queries, and flexible media with picture / srcset.

Lesson 19 Intermediate

💡 The Concept

  • <meta name="viewport" content="width=device-width, initial-scale=1"> — without it, phones render a zoomed-out desktop page.
  • Fluid layouts — percentages, fr units and auto-fit grids that reflow instead of fixed pixel widths.
  • Media queries — @media (max-width: 480px) applies CSS only below that width.
  • srcset / sizes — serve smaller images to small screens; picture offers per-breakpoint art direction.

📝 Source Code

Fluid grid + media query + responsive images 
<!-- viewport meta in <head> -->
<meta name="viewport"
      content="width=device-width, initial-scale=1">

<!-- fluid grid -->
.responsive-demo {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
}

/* media query */
@media (max-width: 480px) {
  .box { background: #fee2e2; }
}

<!-- responsive image (serves different files) -->
<img srcset="small.jpg 480w, large.jpg 1200w"
     sizes="(max-width: 600px) 480px, 1200px"
     src="large.jpg" alt="Example">
💡 Mobile-first: Write the base styles for small screens, then use min-width media queries to enhance larger ones.

✅ Key Takeaways

Remember

  • The viewport meta tag is essential for mobile rendering.
  • Use fluid grids and relative units instead of fixed widths.
  • Media queries adapt styles per screen size.
  • srcset / picture serve the right image to the right device.
