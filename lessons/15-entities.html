Entities & Special Characters

Some characters are reserved by HTML — like < and > — while others are awkward to type. Entities solve both.

Lesson 15 Beginner

💡 The Concept

An entity always starts with & and ends with ;. There are two forms:

  • Named entities — readable, e.g. &copy;.
  • Numeric entities — Unicode code points, e.g. &#169; (same © symbol).

Why do we need them?

  • < and > would be parsed as tag delimiters — writing them literally would break the page.
  • A & could be read as the start of an entity.
  • Spaces you want to preserve need &nbsp; (non-breaking space).

📝 Source Code

Using entities in HTML 
<p>5 &lt; 10 is true.</p>        →  5 < 10 is true.
<p>Copyright &copy; 2026.</p>  →  Copyright © 2026.
<p>Cost: &euro;5 &amp; up.</p>  →  Cost: €5 & up.
<p>Keep &nbsp;words together.</p>
💡 Tip: In HTML you can often type © and € directly thanks to UTF-8 — but the reserved characters (<, >, &) should always be escaped with entities.

✅ Key Takeaways

Remember

  • Entities start with & and end with ;.
  • Always escape <, > and & in content.
  • Named (&copy;) and numeric (&#169;) forms both work.
  • Use &nbsp; to keep words or numbers together.
