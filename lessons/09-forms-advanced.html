Forms — Advanced Controls

Dropdowns, radio buttons, checkboxes, grouped fieldsets, range sliders, colour pickers and native HTML5 validation.

Lesson 09 Intermediate

💡 The Concept

  • select / option — dropdown menus; optgroup groups options under a heading label.
  • input type="radio" — pick exactly one option from a group (shared name). checked preselects one.
  • input type="checkbox" — pick any number of options.
  • fieldset / legend — visually and semantically group related controls; the legend is the group's title.
  • range, color, and datalist (free-text with suggestions) add richness.
  • HTML5 validation: pattern, min, max, and required make the browser validate before submitting.

📝 Source Code

Advanced controls in a grouped fieldset 
<fieldset>
  <legend>Size</legend>
  <input type="radio" name="size" value="small"> Small
  <input type="radio" name="size" value="large"> Large
</fieldset>

<select name="topping" multiple>
  <optgroup label="Classic">
    <option>Cheese</option>
    <option>Pepperoni</option>
  </optgroup>
</select>

<input type="range" min="0" max="5" value="2">
<input type="color" value="#d97706">

✅ Key Takeaways

Remember

  • Radio buttons share a name; only one can be selected.
  • Checkboxes let users select any number of options.
  • fieldset + legend group controls for everyone.
  • Native validation (required, pattern, min/max) runs before any JavaScript.
