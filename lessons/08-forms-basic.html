Forms — Basic Elements

Forms collect user input. A form is wrapped in form, with each field in a label paired to an input.

Lesson 08 Beginner

💡 The Concept

  • <label for="id"> — clicking the label focuses its input. The for attribute must match the input's id.
  • <input type="..."> — the field type changes behaviour: text, email, password, number, date and more.
  • placeholder — ghost text hinting what to type.
  • name — the key sent to the server for this value.
  • required — the browser blocks submission until the field is filled.
  • <textarea> — multi-line text; button and <input type="submit"> submit the form.

📝 Source Code

Label + input pairing with placeholder and required 
<label for="name">Full name:</label>
<input type="text" id="name" name="name"
       placeholder="e.g. Ada Lovelace" required>

<label for="email">Email:</label>
<input type="email" id="email" name="email" required>

<label for="bio">Short bio:</label>
<textarea id="bio" name="bio" rows="3"></textarea>

<button type="submit">Submit</button>
💡 Tip: The for / id pairing is what makes the label clickable and accessible to screen readers.

✅ Key Takeaways

Remember

  • Every field should be paired with a label using for = input id.
  • The type attribute gives mobile keyboards and validation for free.
  • required and placeholder improve usability instantly.
  • Use textarea for multi-line text and button for submitting.
