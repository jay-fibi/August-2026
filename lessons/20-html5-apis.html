HTML5 APIs Introduction

HTML5 brought powerful built-in features: canvas for drawing, details/summary for accordions, dialog for modals, and output for results.

Lesson 20 Intermediate

💡 The Concept

  • canvas — a pixel drawing surface driven by JavaScript (charts, games, art). Requires the <script> to paint on it.
  • details / summary — a JavaScript-free disclosure widget (accordion). Add open to start expanded.
  • dialog — a native modal. Opened with showModal(), closed with close().
  • output — displays the result of a calculation, updated by scripts.
  • Bonus: progress, meter, and datalist are also HTML5.
💡 Note: Some HTML5 APIs (Geolocation, Web Storage, Drag & Drop) need JavaScript. The elements shown here are pure HTML that work out of the box.

<canvas id="c" width="280" height="90"></canvas>
<script>
  const c = document.getElementById('c');
  const ctx = c.getContext('2d');
  ctx.fillStyle = '#2563eb';
  ctx.fillRect(10, 10, 120, 60);   // rounded blue block
  ctx.font = '14px Arial';
  ctx.fillStyle = '#fff';
  ctx.fillText('Canvas!', 36, 46);
</script>

<dialog id="d">...</dialog>  <!-- open via d.showModal() -->

✅ Key Takeaways

Remember

  • details / summary gives accordions without JavaScript.
  • canvas is a drawing surface painted via JavaScript.
  • dialog is the native modal; open with showModal().
  • progress, meter and output are pure-HTML feedback widgets.
