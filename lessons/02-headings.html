Headings & Hierarchy

HTML provides six heading levels, h1 through h6, used to structure content from most to least important.

Lesson 02 Beginner

💡 The Concept

📝 Source Code

A correct heading hierarchy 
<h1>My Recipe Website</h1>
  <h2>Desserts</h2>
    <h3>Chocolate Cake</h3>
      <p>Ingredients and instructions...</p>
    <h3>Apple Pie</h3>
  <h2>Main Courses</h2>
💡 Tip: Headings give structure. If you only need bigger text, style it with CSS — don't reach for a heading tag out of hierarchy.
Headings create the outline of your page — the same way chapters and sections structure a book. Search engines and screen readers use them to understand what your content is about.

  • h1 — the main title. Use it once per page.
  • h2 — major sections under the h1.
  • h3 — sub-sections under an h2, and so on down to h6.
💡 Tip: Never skip levels (e.g. jumping from h1 straight to h3) and never pick a heading just for its size. Use CSS for visual sizing instead — headings carry meaning.

✅ Key Takeaways

Remember

  • Six heading levels exist: h1 to h6.
  • Use one h1 per page for the main title.
  • Keep a logical hierarchy and don't skip levels.
  • Screen readers and SEO rely on headings for structure.
