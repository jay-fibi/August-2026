Paragraphs & Text Formatting

The p tag holds blocks of text, and a family of inline tags add meaning and emphasis: strong, em, mark, and more.

Formatting tags used above

💡 Tip: <strong> and <em> carry meaning; old tags like <b> and <i> are purely visual. Prefer the semantic versions.

Text on the web is wrapped in paragraphs. Inside a paragraph you can use inline formatting elements that add both visual and semantic meaning:

  • strong — important text (bold).
  • em — emphasised text (italic).
  • mark — highlighted / marked text.
  • small — fine print, like disclaimers.
  • del and ins — deleted / inserted text.
  • sub and sup — subscripts and superscripts.
  • br — a line break, and hr — a thematic break (horizontal rule).
💡 Tip: Use <br> sparingly — for addresses or poems. To create vertical space between blocks, use margins in CSS instead.

✅ Key Takeaways

Remember

  • <p> wraps paragraphs; inline tags style text inside them.
  • strong and em add real meaning, not just bold/italic.
  • <br> forces a line break; <hr> adds a thematic divider.
  • Use mark, del, ins, sub, sup for their specific purposes.
