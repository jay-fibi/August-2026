HTML Document Structure

Every web page starts with the same skeleton: a DOCTYPE declaration, an html root element, a head for metadata, and a body for visible content.

Lesson 01 Beginner

💡 The Concept

An HTML document is made up of four essential building blocks that appear in this exact order:

  • <!DOCTYPE html> — tells the browser this is an HTML5 document, so it renders in standards mode instead of quirks mode.

    • 🖥️ Live Demo

    The mini page below shows how the four structural blocks come together:

    ▸ Live Example — A Minimal HTML Page

    Welcome to my first page

    This paragraph lives inside the <body>. The page title above lives in the <head> as a <title> element (look at your browser tab!).

    Right-click this page and choose "View Page Source" — the first line will be <!DOCTYPE html>.

    📝 Source Code

    The 4-part skeleton every page needs 
    <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>Everything visible goes here.</p>
  </body>
</html>

    Notice how the head holds the meta and title tags while the body holds the visible h1 and p content.

  • <html> — the root element that wraps absolutely everything. The lang attribute tells search engines and screen readers which language the page is written in.
  • <head> — invisible metadata: the page title, character encoding, stylesheets, and other setup information.
  • <body> — everything the user actually sees and interacts with: text, images, buttons, and so on.
💡 Tip: Always indent nested elements. Browsers don't care, but your future self (and teammates) will thank you for readable markup.

✅ Key Takeaways

Remember

  • Every HTML page starts with <!DOCTYPE html>.
  • The <html lang="en"> root wraps the whole document.
  • The <head> carries metadata; the <body> carries visible content.
  • Indent nested tags to keep your markup readable.
