Global & Data Attributes

Global attributes work on every element — id, class, style, title, hidden — plus custom data-* attributes for your own data.

Lesson 17 Intermediate

💡 The Concept

  • id — a unique identifier, one per page. Used for anchor links, form labels and JavaScript hooks.
  • class — a reusable label for styling many elements at once.
  • style — inline CSS. Useful for quick tweaks; prefer stylesheets for real projects.
  • title — a tooltip shown on hover.
  • hidden — removes an element from display.
  • data-* — any attribute starting with data- (e.g. data-product-id) carries custom information readable by CSS and JavaScript.
  • lang, dir, tabindex and contenteditable round out the globals.

📝 Source Code

Global + data attributes 
<div id="featured-product"          <!-- unique id -->
     class="product-box"            <!-- reusable class -->
     data-product-id="p-1042"       <!-- custom data -->
     data-in-stock="true"
     title="Hover tooltip">
  ...
</div>

<p hidden>This paragraph is hidden.</p>
<p tabindex="0">Focusable with Tab key.</p>
<p contenteditable="true">You can edit me!</p>
💡 Tip: Keep id values unique across the page — duplicates break anchors, labels and JavaScript selectors.

✅ Key Takeaways

Remember

  • id must be unique; class can repeat.
  • Global attributes work on every element.
  • data-* stores custom data readable via dataset.
  • Prefer classes over inline style in real projects.
