Tables

The table element organises data into rows and columns. Modern HTML groups it with thead, tbody and tfoot.

Lesson 07 Beginner

💡 The Concept

  • tr — a table row; th — a header cell (bold, centred); td — a data cell.
  • caption — a visible title for the table.
  • colspan — a cell that stretches across multiple columns.
  • rowspan — a cell that stretches down multiple rows.
  • scope on th tells screen readers whether the header applies to its column or its row.
💡 Tip: Tables are for tabular data, not page layout. To arrange cards and columns, use CSS Grid or Flexbox instead.

📝 Source Code

Table with thead, tbody, tfoot and colspan 
<table>
  <caption>Table 1 — Season results</caption>
  <thead>
    <tr><th scope="col">Team</th><th scope="col">Points</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">Red Rovers</th><td>30</td></tr>
    <tr><th scope="row">Blue United</th><td>27</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="2">Total</td></tr>
  </tfoot>
</table>

✅ Key Takeaways

Remember

  • Tables are built from tr (rows), th (headers) and td (cells).
  • thead / tbody / tfoot group rows for styling and semantics.
  • colspan and rowspan merge cells.
  • Use scope on headers for screen readers.
