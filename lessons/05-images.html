Images & Alt Text

The img element embeds pictures into a page. It is a void element — it has no closing tag — and its two most important attributes are src and alt.

Lesson 05 Beginner

🖥️ Live Demo

Three images, including a captioned figure and a lazy-loaded one:

▸ Live Example — Images

📝 Source Code

img, figure, figcaption, lazy loading 
<img src="photo.jpg" alt="A mountain at sunset" width="300" height="180">

<figure>
  <img src="photo.jpg" alt="A mountain at sunset" loading="lazy">
  <figcaption>Fig. 1 — Mount Everest at sunset</figcaption>
</figure>
💡 Tip: Always write a descriptive alt. If the image fails or the user is blind, the alt text becomes the content.

💡 The Concept

  • src — the path or URL of the image file.
  • alt — a text description. It shows if the image fails to load and is read aloud by screen readers. It's also used by search engines.
  • width / height — reserve space and prevent layout shifting while the image loads.
  • figure / figcaption — pair an image with a caption.
  • loading="lazy" — defer off-screen images until the user scrolls to them.
💡 Tip: For decorative images that add no information, use an empty alt="" so screen readers skip them entirely.

✅ Key Takeaways

Remember

  • The img tag needs src and a descriptive alt.
  • width/height prevent layout jumps while images load.
  • figure + figcaption add captions.
  • loading="lazy" speeds up pages with many images.
