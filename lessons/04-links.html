Hyperlinks & Anchors

The a (anchor) element turns text or images into clickable links, connecting pages across the web and inside your own site.

Lesson 04 Beginner

📝 Source Code

The five link patterns 
<a href="../index.html">Internal link</a>
<a href="#top">Anchor within page</a>
<a href="https://example.com" target="_blank" rel="noopener">External link</a>
<a href="mailto:you@mail.com">Email me</a>
<a href="tel:+15550123">Call us</a>
⚠️ Note: Adding rel="noopener" to every target="_blank" link stops the new page from accessing window.opener — a common security best practice.

💡 The Concept

A link's destination lives in the href attribute. The value can be a full URL, a relative path, an email address, or even a phone number:

  • href="https://example.com" — absolute URL to another site.
  • href="page2.html" — relative path within your site.
  • href="#section" — jump to an element with that id.
  • href="mailto:you@mail.com" — opens the email client.
  • href="tel:+15550123" — dials a number on mobile.

The target="_blank" attribute opens the link in a new tab. Always pair it with rel="noopener" for security.

✅ Key Takeaways

Remember

  • Links are made with the a element and an href attribute.
  • href can be absolute, relative, an anchor, mailto: or tel:.
  • target="_blank" opens a new tab — pair it with rel="noopener".
  • Links work on text and images alike.
