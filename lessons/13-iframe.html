iframes & Embedding

An iframe embeds another HTML document inside the current page — the technique behind embedded maps, videos and widgets.

Lesson 13 Intermediate

💡 The Concept

  • src — the URL of the page to embed.
  • srcdoc — embed inline HTML directly, no separate file needed (perfect for sandboxed demos like the one below).
  • width / height — frame size; title — a label for screen readers (required for accessibility).
  • loading="lazy" — defer off-screen frames.
  • sandbox — restrict what the embedded page can do (scripts, forms, popups...). An empty value allows nothing.
⚠️ Note: Many sites (e.g. google.com) send an X-Frame-Options header that blocks embedding. That's a security feature — and a reason srcdoc is great for demos.

📝 Source Code

srcdoc and src iframes 
<iframe srcdoc="<p>Hello from inline HTML</p>"
        title="Inline demo"></iframe>

<iframe src="https://example.com/widget"
        title="External widget"
        width="400" height="300"
        loading="lazy"></iframe>
💡 Tip: Give every iframe a descriptive title — screen reader users rely on it to know what the frame is.

✅ Key Takeaways

Remember

  • iframe embeds one HTML document inside another.
  • srcdoc embeds inline HTML without a separate file.
  • Always set a descriptive title for accessibility.
  • Use sandbox to restrict untrusted embedded content.
