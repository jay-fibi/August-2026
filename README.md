# HTML Learning Hub

An interactive online learning resource for HTML — 20 hands-on lessons, each with a **live code editor**, a working demo, source code breakdowns and key takeaways.

## Features

- **20 lessons** covering core HTML concepts (structure, headings, text, links, images, lists, tables, forms, semantic HTML, media, iframes, meta tags, entities, comments, attributes, accessibility, responsive design, HTML5 APIs)
- **Live HTML editing** — every demo can be edited in-browser; the preview updates as you type, with a one-click reset
- **Accounts & progress tracking** — sign up / log in, mark lessons complete, and your progress is saved per account (stored in `localStorage` — a client-side demo, not production auth)
- **Modern dark UI** — glassmorphism navigation, gradient accents and smooth animations (pure HTML/CSS/JS, no dependencies)

## Structure

```
html-learning-hub/
├── index.html          # Home page / dashboard with progress
├── css/styles.css      # Shared modern theme
├── js/app.js           # Auth, progress, and live editor engine
└── lessons/            # 20 lesson pages (01-20)
```

## Getting started

Open `index.html` in any modern browser — no build step or server required.
