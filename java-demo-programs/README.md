# Java Demo Programs

This folder contains six standalone Java programs:

1. `HelloWorldDemo.java` - variables and console output
2. `EvenOddDemo.java` - conditional statements
3. `MultiplicationTableDemo.java` - a `for` loop
4. `ArrayStatisticsDemo.java` - arrays, iteration, and calculations
5. `PalindromeDemo.java` - string processing
6. `SimpleCalculatorDemo.java` - a simple calculator with methods and exception handling

## Compile all programs

```sh
javac *.java
```

## Run a program

```sh
java HelloWorldDemo
java EvenOddDemo
java MultiplicationTableDemo
java ArrayStatisticsDemo
java PalindromeDemo
java SimpleCalculatorDemo
```
